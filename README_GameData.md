# DCS Spatial System Specification

Высокопроизводительная пространственная подсистема движка DCS. Предназначена для асинхронного стриминга данных локаций, быстрого определения нахождения динамических объектов внутри зон (триггеров) произвольной формы и поиска окружения (укрытия, точки зацепа) с минимальной нагрузкой на CPU.

## 1. Архитектурный принцип

Система построена на строгом разделении конвейера данных по принципу:
**Authoring (Редактор Unity) → Compiled Data (Сериализованный ассет) → Runtime Storage (CPU-кэш симуляции).**

*   **Изоляция визуала и логики:** Компоненты на сцене (`Zone`, `ZoneVolume`, `ZoneBorder`, `Spawner`) служат только интерфейсом для геймдизайнера (Слой Authoring). В рантайме их `MonoBehaviour` и физические коллайдеры полностью уничтожаются/выгружаются. Рантайм оперирует сухими структурами данных.
*   **0 Garbage Collection (Blittable структуры):** Все рантайм-запросы, циклы narrowphase и методы пересечения работают без динамических аллокаций памяти (`0 GC`).
*   **Двухфазный поиск (Broadphase / Narrowphase):** Для быстрого отсечения используется трехмерная хэш-сетка (`Spatial Hash Grid`) на основе честных оффлайн-границ AABB. Точная геометрия (OBB, Сферы, Треугольники) вычисляется только для прошедших кандидатов.

## 2. Компоненты системы

### Элементы компиляции (Editor Only)
*   **GeometryCompiler:** Превращает `BoxCollider` в точные параметры OBB (`BoxGeometry`), `SphereCollider` — в радиусы (`SphereGeometry`). Вычисляет точный мировой AABB для broadphase-сетки.
*   **ZoneCompiler:** Автоматически триангулирует (нарезает «веером») плоские полигональные границы зон `ZoneBorder` в плоский массив `TriangleGeometry` и связывает их с логическим ID зоны.
*   **WorldPacker:** Статический оффлайн-сборщик. Проходит по сцене, вызывает компиляторы и запекает результат в единый ассет `MapDataset`. Не влияет на рантайм-состояние игры в редакторе.

### Данные и Рантайм-хранилище
*   **MapDataset (ScriptableObject):** Контейнер данных карты. Хранит массивы метаданных (`ZoneRecord`, `SpawnerRecord`, `LocatorRecord`), массив `SpatialProxy` для сетки и специализированные массивы геометрии (`Spheres`, `Boxes`, `Triangles`).
*   **RuntimeGeometryStorage:** Плоский буфер активной геометрии в оперативной памяти. Предоставляет доступ к структурам по `ref readonly` для исключения копирования тяжелых данных в стек.

### Поисковый движок и Системы
*   **SpatialIndex:** «Слепая» математическая структура данных. Регистрирует индексы прокси-объектов в кубические ячейки пространства заданного размера (`_cellSize`). Возвращает только `OwnerId` объектов, прошедших геометрический фильтр. Ничего не знает про Lua и компоненты игры.
*   **SpatialRuntime:** Синглтон-обертка над индексом, обеспечивающая C# и Lua интерфейс к пространственным запросам в точке или в радиусе.
*   **ZoneDetectionSystem:** Изолированный наблюдатель. Раз в $N$ кадров запрашивает у `SpatialRuntime` состояние зон вокруг игрока, вычисляет разницу состояний (Паттерн Horizon Enter/Exit) и генерирует события.

### Стриминг и Интеграция
*   **DatasetLoader:** Асинхронный конвейер. Запускает параллельный стриминг: через `SceneManager.LoadSceneAsync` подгружает визуал (меши, свет), одновременно считывает `MapDataset`, регистрирует геометрию в индекс и разворачивает сущности в пулы компонентов. Передает точный прогресс загрузки в Lua.
*   **LuaSpatialBridge:** Шлюз маршалинга. Отвечает за вызов Lua-функций из C# (передача событий входа/выхода/завершения стриминга) и экспорт C#-методов пространственного поиска в контекст виртуальной машины Lua.

## 3. Спецификация Lua API

Экспортируемые в глобальное окружение Lua функции:

```lua
-- Запустить асинформную фоновую загрузку сцены и её датасета
Map.Stream("SwampZone")

-- Полностью очистить память и выгрузить активную карту
Map.Unload()

-- Получить текущий статус стриминга
-- Возвращает: state (string: "Unloaded"|"Loading"|"Loaded"), mapName (string), progress (number: 0.0-100.0)
local state, mapName, progress = Map.GetStatus()

-- Запрос окружения в радиусе (ИИ укрытия, точки зацепа паркура)
-- Аргументы: x, y, z, radius, objectType (0: ZoneTrigger, 1: CombatCover, 2: GrapplePoint, 3: InteractableNode)
-- Возвращает: массив (table) уникальных OwnerId объектов
local ids = Spatial.QueryNearby(enemyX, enemyY, enemyZ, 15.0, 1)
```

Система реагирует на входящий вызов от C# через единый роутер:
```lua
function DCS_Spatial_EventRouter(eventName, id)
    -- eventName: "OnZoneEntered", "OnZoneExited", "OnMapStreamingFinished"
    -- id: HostId логической зоны или 0 для системных событий
end
```
